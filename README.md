# Lernplattformen Technik

Interaktive Lernplattformen und Fortbildungsangebote für den AWT-Unterricht (Arbeit – Wirtschaft – Technik) von Daniel Beyrodt, Fachmoderator AWT, RLSB Hannover („dein Technik Lehrer“).

**Startseite mit allen Plattformen:** https://beyrodthome.github.io/Lernplattformen/

| Plattform | Adresse |
|---|---|
| Arduino-Lernheft Tinkercad | [/arduino-lernheft/](https://beyrodthome.github.io/Lernplattformen/arduino-lernheft/) |
| Arduino Schritt für Schritt | [/arduino-schritt-fuer-schritt/](https://beyrodthome.github.io/Lernplattformen/arduino-schritt-fuer-schritt/) |
| Arduino-Challenges | [/arduino-challenges/](https://beyrodthome.github.io/Lernplattformen/arduino-challenges/) |
| Arduino-Challenges: Druckvorlagen | [/arduino-challenges/material/](https://beyrodthome.github.io/Lernplattformen/arduino-challenges/material/) |
| Elektroinstallation | [/elektroinstallation/](https://beyrodthome.github.io/Lernplattformen/elektroinstallation/) |
| 3D-Druck mit dem Ender 3 V2 | [/3d-druck/](https://beyrodthome.github.io/Lernplattformen/3d-druck/) |
| AI Badge (Schülerfassung) | [/ai-badge/](https://beyrodthome.github.io/Lernplattformen/ai-badge/) |
| AI Badge – Fortbildung (Lehrkräfte, Passwort) | [/ai-badge-lehrkraefte/](https://beyrodthome.github.io/Lernplattformen/ai-badge-lehrkraefte/) |
| Bedürfnis-Werkstatt | [/beduerfnis-werkstatt/](https://beyrodthome.github.io/Lernplattformen/beduerfnis-werkstatt/) |
| Einkommens-Werkstatt | [/einkommens-werkstatt/](https://beyrodthome.github.io/Lernplattformen/einkommens-werkstatt/) |
| Arbeits-Werkstatt | [/arbeits-werkstatt/](https://beyrodthome.github.io/Lernplattformen/arbeits-werkstatt/) |
| MakerSpace-Kompass | [/makerspace-kompass/](https://beyrodthome.github.io/Lernplattformen/makerspace-kompass/) |
| KI verstehen – vom Wissen zum eigenen KI-System | [/ki-verstehen/](https://beyrodthome.github.io/Lernplattformen/ki-verstehen/) |

Jede Plattform ist eine eigenständige HTML-Seite. Es gibt keinen Server und keine Anmeldung: Der Lernstand bleibt im Browser des jeweiligen Geräts. Lösungen für Lehrkräfte liegen nur verschlüsselt im Repository und lassen sich mit dem Lehrkräfte-Passwort öffnen.
